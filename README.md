# 🕵️ Semantic Blur Quiz (Семантическая Викторина)

**Semantic Blur Quiz** — это образовательная WebGL-игра, объединяющая визуальное распознавание и семантический анализ текста. Игроку нужно угадать объект на сильно пикселизированном изображении, вводя ответы и используя синонимы.

## 🎮 Ключевые механики
* **Динамическая пикселизация**: Картинка скрыта за шейдером размытия. Правильный ответ (`Win`) делает её чёткой. Ошибка (`Wrong`) немного проясняет изображение. Ввод синонима (`CloseMatch`) — **увеличивает размытие**, наказывая за попытки "заспамить" систему.
* **Умная верификация**: Игра понимает не только точное слово, но и словоформы, а также семантически близкие понятия.
* **Кэширование синонимов**: Повторный ввод уже использованного синонима (`Ignore`) не штрафуется, но и не помогает.
* **Галерея прогресса**: Коллекция угаданных предметов с сохранением прогресса через `PlayerPrefs`.

## 🛠 Технический стек и Архитектура
Проект спроектирован с упором на чистую архитектуру, масштабируемость и поддержку браузерной платформы.

* **Движок**: Unity (WebGL 2.0)
* **Язык**: C# (Async/Await, Task-based Asynchronous Pattern)
* **Библиотеки**: Unity Localization, TextMeshPro
* **Архитектурные паттерны**:
  * **MVC**: Для изоляции логики UI-панелей (Таймер, Галерея, Результаты, Правила).
  * **Factory Method**: `QuizServiceFactory` для внедрения зависимостей (DI) и создания сервисов.
  * **Observer**: Событийная модель (`event Action`) для развязки компонентов.
  * **Repository**: `WordsCache` для кэширования тяжелых строковых массивов из системы локализации.

### ⚡ Решенные технические вызовы (Highlights)
1. **Обход ограничений WebGL (Synchronous Loading)**: 
   Unity WebGL не поддерживает многопоточность. Синхронная загрузка Addressables/Localization приводила к крашу игры (`WebGLPlayer does not support synchronous Addressable loading`). **Решение:** Весь пайплайн загрузки данных (локализация, проверка ответов, словари) был полностью переведен на `async/await`, а методы жизненного цикла адаптированы для работы с `Task`.
2. **Кастомная математика шейдеров**: 
   Эффект размытия управляется через uniform-переменную `_PixelSize`. Для плавной анимации перехода от сильного размытия к четкой картинке (при выигрыше) реализована адаптивная функция интерполяции (`Mathf.Lerp` с динамическим `Clamp` скорости), предотвращающая резкие скачки.
3. **Оптимизация памяти**: 
   Строки локализации загружаются асинхронно и кэшируются в `Dictionary`. При смене языка кэш автоматически инвалидируется (`OnLanguageChanged`), предотвращая утечки памяти.

## 📂 Структура проекта
```text
Assets/
├── Scripts/
│   ├── Core/           # Главные контроллеры (GameLoop, MainMenu, Audio)
│   ├── Verification/   # Сервис проверки ответов и кэш слов
│   ├── Progression/    # Управление шейдером пикселизации
│   ├── Localization/   # Асинхронный менеджер языков
│   ├── Json/           # Парсинг и управление уровнями
│   ├── Gallery/        # MVC галереи (Model-View-Controller)
│   ├── EndPanel/       # MVC панели результатов
│   └── UI/             # Компоненты интерфейса
├── Resources/          # JSON-конфиги уровней и спрайты
└── Localization/       # Таблицы переводов (ru/en)
```

🚀 Как запустить локально

    Клонируйте репозиторий.

    Откройте проект в Unity (версия указана в ProjectVersion.txt).

    Перейдите в File -> Build Settings, выберите WebGL.

    В Player Settings -> Publishing Settings:

        Установите Compression Format: Disabled.

        Включите галочку Decompression Fallback.
